## 근무형태 5종 (v1.6.14)

승무 3종(지선·본선 기관사·본선 차장) 외에 사업소 근무형태 2종을 추가했다.
`CrewGroup` enum이 5개(BRANCH·MAIN_DRIVER·MAIN_CONDUCTOR·**SHIFT_4_2·OFFICE_DAY**)가 됐고,
`CrewRole`에 `OPERATION`(기존)·**`OFFICE_STAFF`**(신규)를 쓴다.

- **4조2교대**(운용조·기지관제, `bundled-shift42`): 순환 `[비번, 휴무, 주간, 야간]`, 4일 주기.
  A/B/C/D조 = offset 0/1/2/3. **anchor = 2026-08-10**.
  근거: 사용자 확정 "8/10(월) A조=비번". anchor를 8/10에 두면 그날 days=0,
  A조 offset 0 → `sequence[floorMod(0+0,4)]`=`sequence[0]`이 비번이어야 하므로 비번부터 이어
  적어 `[비번,휴무,주간,야간]`. 검산: A조 8/10비번·8/11휴무·8/12주간·8/13야간·8/14비번.
  같은 8/10에 B조=휴무·C조=주간·D조=야간(조가 하루씩 앞섬). **실화면 확인 완료**(A/B/통상 스샷).
  근무선택 2단계는 29칸 다이아 대신 A·B·C·D 4카드(각 카드에 그날 근무를 칩으로 표시).
- **통상근무**(사무실·소장/부사업소장·지도과·관리과, `bundled-office`): 월~금 주간, 토·일·공휴일 휴무.
  순환은 `["주간"]` 1칸뿐이고 **`Pattern.restOnHolidays=true`**가 토·일·법정공휴일을 "휴무"로 덮는다.
  **공휴일 처리 위치 = `Pattern.dutyOn`**(UseCase가 아니라). 이유: 달력·동료매트릭스·위젯·Mate·
  관리자 미리보기가 전부 `dutyOn` 하나로 근무를 뽑아서 — UseCase에서만 덮으면 동료화면·위젯에
  공휴일이 근무일로 남는다. 상수 테이블(`Bundled.isHolidayTimetable`)만 읽어 순수성은 유지.
  대체공휴일도 `PUBLIC_HOLIDAYS`에 있으면 자동 반영(8/15 광복절·8/17 대체휴일 휴무 실화면 확인).
  조 구분이 없어 근무선택 1단계에서 소속 카드를 누르면 **2단계 없이 바로 확정**(`pattern.length==1`).
- 표시 문자열: `DutyCode.parse`에 `"주간"→MAIN_DAY, "야간"→MAIN_NIGHT` 매핑 추가,
  `display`에서 `"비번"`은 `~`가 아니라 글자 그대로, `"휴무"`는 REST 계열이라 그대로 나온다.
  기존 색·칩·야간 초승달 배지 로직 그대로 재사용(야간=보라+초승달, 비번=회색 off, 휴무=빨강 rest).
