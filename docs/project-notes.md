  폭이 최대인 FillWidth 상태에선 세로를 못 키웁니다. 그래서 `RouteImageInline(zoom=1.5f)`로
  폭을 1.5배 키우고 넘치는 폭은 가로 스크롤(오른쪽 주행계·전반/후반 통계표가 스크롤 밖).
  세로 공간은 `ModalBottomSheet(skipPartiallyExpanded = true)`로 확보. 되돌리려면 zoom을 1f로.
  펼침 오른쪽 패널은 zoom 1f 유지 — 이미 크고 가로 스크롤이 필요 없습니다.
- **인라인 행로표 배율: 본선 1.8배 / 지선 1.5배**(v1.6.8, 접힘만). 원본 비율이 본선 ~2.1:1,
  지선 ~1.41:1로 달라서 공통 1.5배면 본선만 납작해 보입니다("지선만 커졌나?"). 접힘 폰 411dp
  기준 본선 세로 ~335dp(1.5배였을 땐 ~282dp), 지선은 ~423dp로 종전과 동일.
  `MainCalendarScreen.kt`의 `val zoom = if (!compact) 1f else if (day.duty.isBranch) 1.5f else 1.8f`.
- **달력 칸 폰트·공휴일 이름 배치**(v1.6.8). 날짜 숫자 `7.5→7sp`(big `9.5→9sp`), 날짜 알약 여백
  `horizontal 4→2dp` / `start 3→2dp`로 이름에 폭을 양보. 이름은 `HolidayTag`가 폭을 넘치면
  0.92배씩 자동 축소(하한 5sp) — 다이아 칩·시각표 카드와 같은 방식.
  배치는 **칸 폭**으로 갈립니다(`CalendarGrid`의 `nameBelow = 칸폭 < 45dp`):
  접힘 폰 칸 ~54dp면 날짜 옆 한 줄, 펼침 44% 달력 칸 ~37dp면 날짜 아랫줄 전체 폭.
  **칸 높이(`big`)로 가르면 안 됩니다** — 5주 달(7월)과 6주 달(8월)에서 값이 뒤집혀 월마다 배치가 달라집니다.
